# React Music Player

A music player built using React, JavaScript, and CSS. The application fetches song information from the iTunes Search API and allows users to listen to audio previews through an interactive interface.

## Features

- Fetches songs dynamically from the iTunes Search API
- Displays album artwork, song titles, and artist names
- Play and pause audio previews
- Skip between songs
- Adjustable volume control
- Interactive audio progress bar
- Displays playback time and remaining duration
- Animated album artwork during playback

## Technologies Used

- React
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- iTunes Search API
- Lucide React

## What I Learned

Through this project, I practiced React hooks, managing component state, working with audio elements using `useRef`, fetching asynchronous data from an external API, and updating the user interface based on playback state.

## Notes

Audio playback uses short previews provided by the iTunes Search API rather than full-length songs.
